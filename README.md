ПРАКТИКА 9:

Определить комбинированный (структурный) тип для представления анкеты ребенка,
состоящей из его имени, пола, роста, даты рождения. Ввести информацию по 20 детям. 
Вывести средний рост мальчиков. Перенести в отдельный массив 5 самых высоких девочек. 
Отсортировать список учеников в лексикографическом порядке. Вывести все данные по 
конкретному ученику (по фамилии ученика). Реализовать функцию изменения данных 
конкретного ученика. В отдельный массив поместить список детей, имеющих день рождения 
в текущем месяце. Реализовать вывод отфильтрованных данных в виде оберточной функции.
